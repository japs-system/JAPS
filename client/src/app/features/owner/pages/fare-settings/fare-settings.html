How it works

Base Fare Formula

if distance ≤ base_distance_km: min_fare
else: min_fare + ((distance − base_distance_km) × rate_per_km)

Final Fare

base_fare × (1 − category_discount_percent / 100)

The conductor app uses these settings to compute fares during ticketing. The minimum fare covers the base distance, then each additional km adds the per-km rate. Changes apply system-wide.
